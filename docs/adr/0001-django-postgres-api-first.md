# ADR-0001: Django + PostgreSQL, API-first

**Status:** accepted · 2026-11-13

## Context
Потрібен прототип веб-сервісу запису, а далі — мобільний застосунок власника. Команда й інфраструктура вже стандартизовані: Python/Django, PostgreSQL, Docker на AWS ECS.

## Decision
- Один Django-проєкт, PostgreSQL 16 (локально в контейнері `db`).
- Бізнес-логіка в доменних модулях (`booking.engine`, `storage.services`); веб (Django templates) і REST API v1 (DRF, `/api/v1/`) — тонкі адаптери над ними.
- Веб-UI рендериться на сервері без SPA-фреймворку: менше рухомих частин; мобільний застосунок піде на REST API.

## Consequences
- Мобільний застосунок не потребує змін бекенду, лише нових ендпоінтів за потреби.
- Правила доступності не дублюються між вебом і API.
