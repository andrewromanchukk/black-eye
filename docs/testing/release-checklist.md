# Перевірки перед релізом Zapik

Що перевіряють перед кожним релізом, у порядку бізнес-ризику: зверху те, що найдорожче коштує, якщо зламається. Для кожної перевірки вказано, що вже покривають автотести (`tests/`, запускаються в CI на кожен push) і що поки перевіряється вручну.

Реальна доставка SMS у цей список не входить: на початковому етапі цього функціоналу не буде.

|---|---|---|---|---|
| 1 | **Публічна сторінка запису → слот заброньовано.** Відкрити `/w/<warsztat>/` → обрати послугу → день → вільний слот → ім'я, телефон, номер авто, згода → «Rezerwuję» → «Rezerwacja potwierdzona». Заброньований слот більше не пропонується. | Головна цінність продукту і гроші автосервісу.
