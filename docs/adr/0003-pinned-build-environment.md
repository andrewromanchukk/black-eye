# ADR-0003: Зафіксоване середовище збірки

**Status:** accepted · 2026-11-16

## Context
Збірка залежала від плаваючих тегів (`python:3.13-slim`, `postgres:16-alpine`) і лише прямих версій пакетів; транзитивні залежності, pip і базова ОС змінювались між збірками.

## Decision
Базові образи — точний тег + digest; pip — точна версія; пакети — lock-файл `requirements.txt` з хешами, згенерований pip-tools із `requirements.in`, встановлення з `--require-hashes`. Оновлення лише свідомі, за `docs/build-environment.md`.

## Consequences
- Однакові збірки на будь-якій машині й архітектурі; підміну пакета pip відхиляє.
- Оновлення безпеки не приходять «самі» — потрібен регулярний процес (місяць / CVE), пізніше Renovate.
